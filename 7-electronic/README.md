# Electronic X

Сайт магазина электроники: bento-сетка, каталог с фильтрами и поиском, калькулятор рассрочки.

## Файлы
- `index.html` — разметка
- `style.css` — стили; цвета в `:root`
- `images/` — фотографии (JPG)
- `script.js` — фильтр и поиск, корзина, калькулятор рассрочки

## Запуск
Откройте папку в VS Code → Go Live, или откройте `index.html` в браузере.
