# 4 Flowers Store

Сайт цветочного магазина. Адаптивный, светлая и тёмная тема.

## Файлы
- `index.html` — разметка
- `style.css` — стили; цвета в `:root`
- `images/` — фотографии (JPG)
- `script.js` — карусель и счётчик корзины

## Запуск
Откройте папку в VS Code → Go Live, или откройте `index.html` в браузере.
