# Glow Beauty

Сайт бьюти-бутика в тёмной роскошной стилистике.

## Файлы
- `index.html` — разметка
- `style.css` — стили; цвета в `:root`
- `images/` — фотографии (JPG)
- `script.js` — избранное и корзина, подбор оттенка, смена отзывов, форма рассылки

## Запуск
Откройте папку в VS Code → Go Live, или откройте `index.html` в браузере.
