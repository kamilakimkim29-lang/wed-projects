# 2-Milk Company

Лендинг молочной компании (адаптивный, со светлой и тёмной темой).

## Файлы
- `index.html` — разметка страницы
- `style.css` — стили и цвета (переменные в `:root`)
- `images/` — картинки упаковок 
- `script.js` — стрелки карусели «Хиты нашей линейки»

## Запуск
1. Откройте папку в VS Code (File → Open Folder).
2. Нажмите **Go Live** (расширение Live Server) или откройте `index.html` в браузере.

## Что менять
- Название, тексты, цены, контакты — в `index.html`.
- Цвета — переменные `--green`, `--blue`, `--red` в начале `style.css`.
- Картинки — файлы в папке `images/`, пути прописаны в `index.html`.
